**Retail Sales Analytics Dashboard | Power BI**

**Overview**
An interactive Power BI dashboard created to analyse sales, profit, orders, and product performance.

**Tools Used**
- Power BI Desktop
- Power Query
- DAX
- Microsoft Excel
- 
**Key Metrics**
- Total Sales
- Total Profit
- Profit Margin
- Total Orders
- Average Order Value
- 
**Dashboard Features**
- Monthly sales trend
- Product-wise sales analysis
- Profit margin comparison
- Interactive filters and slicers
- 
**Project Workflow**
1. Imported Excel data into Power BI.
2. Cleaned and transformed data using Power Query.
3. Created relationships between tables.
4. Built DAX measures for business metrics.
5. Designed an interactive dashboard.
6. 
**Skills Demonstrated**
Data cleaning, data modelling, DAX calculations, data visualisation, and dashboard design.

**How to Use**
Download the .pbix file and open it in Power BI Desktop. Use the slicers to explore performance for different selections.
